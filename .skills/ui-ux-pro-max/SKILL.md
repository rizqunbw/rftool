# UI/UX Pro Max — Project Rules

Source: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

Apply these rules to this project:
- keep one semantic token system for background, surface, foreground, muted, border, ring and danger
- compact utility-first layout; avoid oversized marketing cards
- maintain strong hierarchy with restrained typography
- essential text must reflow and long filenames must truncate safely with accessible title
- visible keyboard focus on interactive controls
- native semantics for buttons, inputs, checkboxes and selects
- never rely on color alone for state
- reduced-motion friendly animation
- responsive layout must preserve editor usability
- keep business logic unchanged during visual refactors
- audit hover, focus, disabled and error states

Target style for RF Online Tools: monochrome minimal utility editor, black/white, high contrast, restrained radii, minimal shadow, no gradient-heavy AI-dashboard look.
