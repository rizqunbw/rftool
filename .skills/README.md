# Project Skills

This folder documents the UI/UX sources intentionally used by this project.

- `framer-motion/` — motion/interaction reference for the React UI.
- `ui-ux-pro-max/` — project-local summary of UI/UX Pro Max guidance used for audits and redesigns.
- `21st-dev/` — component-pattern reference for polished React UI composition.

These files are project references, not vendored copies of third-party repositories.
